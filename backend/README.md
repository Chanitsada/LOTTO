# Backend

Use Node.js, Express and mysql2/promise, starting with app.js, db.js, routes,
controllers and middleware. Follow the [folder guide](../docs/02-architecture.md)
for the planned structure. There is no server/package.json yet; I will add run commands with the code.

## Responsibilities

- **My tasks:** I handle setup, login/roles, checkout and reporting.
- **Backend teammate:** Handle DB setup, draws, inventory, history and results.

Follow the [task checklist](../docs/backend-allocation.md) and
[API notes](../docs/03-api-contract.md). Include SQL and checks with each feature.
I approve my teammates' PRs into main.
